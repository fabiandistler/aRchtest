# aRchtest

ArchUnit for R — declare dependency rules between modules and enforce
them in `testthat`.

## Agent skills

### Issue tracker

Issues and specs live as GitHub issues in `fabiandistler/aRchtest`,
managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, each label string equal to its name.
See `docs/agents/triage-labels.md`.

### Domain docs

Single-context — one `CONTEXT.md` and one `docs/adr/` at the repo root.
See `docs/agents/domain.md`.
